## Event-B спецификация

Публично доступная часть Event-B спецификации иерархической интегрированной модели
управления доступом и информационными потоками (модель **HIMACF**, ранее известная как
МРОСЛ ДП-модель) размещена в отдельном репозитории:
**[eventb-rossi/rbac-model](https://github.com/eventb-rossi/rbac-model)**.
